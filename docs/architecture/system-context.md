## 3. Containers — target

Every client goes through the same API (ADR-0011). The engine runs inside the API and
workers; mobile and web can also run it locally for instant previews (ADR-0003, ADR-0005).

```mermaid

    partner["Partner backends<br/>(Tax API, SDKs)"]:::planned
  end

  subgraph backend["Backend"]
    api["apps/api<br/>App API (session auth)<br/>Partner API /v1 (API keys)"]:::planned
    worker["apps/worker<br/>import · sync · calculate · reports"]:::planned
```

## 4. Deployment — target

Data residency matters for DAC8 tenants ([security spec](../spec/security-privacy-spec.md)),
so each region is a self-contained stack.

```mermaid
flowchart LR
  dns["Global DNS / CDN"]:::planned
  subgraph us["Region: US"]
    us_api["API + web"]:::planned
    us_wk["Workers"]:::planned
    us_db[("Postgres")]:::planned
    us_obj[("Object storage")]:::planned
  end
  subgraph eu["Region: EU (DAC8 tenants)"]
    eu_api["API + web"]:::planned
    eu_wk["Workers"]:::planned
    eu_db[("Postgres")]:::planned
    eu_obj[("Object storage")]:::planned
  end
  subgraph jp["Region: Japan (option)"]
    jp_api["API + web"]:::planned
  end
  dns --> us_api
  dns --> eu_api
  dns -.-> jp_api
  us_api --> us_db
  us_wk --> us_db
  us_wk --> us_obj
  eu_api --> eu_db
  eu_wk --> eu_db
  eu_wk --> eu_obj

  classDef planned fill:#eef0f4,stroke:#8a93a3,color:#3b4250,stroke-dasharray: 5 4
```

Tenant data never crosses regions. Rule packs and engine versions are identical in every
region, so the same input gives the same output anywhere (ADR-0006).
